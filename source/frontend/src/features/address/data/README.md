# Vietnam administrative-unit data

`administrativeUnits.json` is a compact copy of the province-level and
commune-level data used by the address dropdowns.

- Source: Dia Chi Viet, Vietnam administrative units open data
- Source URL: https://diachiviet.com/du-lieu-mo/
- Upstream repository: https://github.com/HuyChuong/vietnam-administrative-units
- License: CC BY 4.0
- Legal documents reflected through: 20 September 2026

The administrative names intentionally remain in their official Vietnamese
form in both website languages. Only interface labels and instructions are
translated.

This data is provided for reference. Official documents and confirmation from
the competent authority prevail.
